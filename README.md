# Aurelle Premium Perfume Website

A five-page static HTML and Bootstrap 5 perfume website with a reference-matched premium homepage.

## Pages

- `index.html` — animated product-slider homepage
- `collection.html` — fragrance collection and family filters
- `story.html` — maison story and production process
- `journal.html` — editorial fragrance journal
- `contact.html` — client-side enquiry form

## Homepage experience

- Minimal animated percentage loader
- Full-screen colour-changing fragrance hero
- Three interactive perfume themes and auto-play slider
- Botanical product presentation with layered depth
- Infinite announcement ticker and curved section transition
- Editorial discovery mosaic
- Drag-to-scroll fragrance mood carousel
- Customer story cards
- Promotional offer panels and newsletter sign-up
- GSAP reveal/parallax motion and Lenis smooth scrolling
- Reduced-motion support
- Responsive desktop, tablet and mobile layouts

## Run locally

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`.

## Stack

- Static HTML5
- Bootstrap 5.3
- Bootstrap Icons
- GSAP + ScrollTrigger
- Lenis smooth scroll
- Vanilla JavaScript

# Aurelle Premium Perfume Website

A five-page PHP and Bootstrap 5 perfume website with a reference-matched premium homepage.

## Pages

- `index.php` — animated product-slider homepage
- `collection.php` — fragrance collection and family filters
- `story.php` — maison story and production process
- `journal.php` — editorial fragrance journal
- `contact.php` — enquiry form

## Homepage experience

- Minimal animated percentage loader
- Full-screen colour-changing fragrance hero
- Three interactive perfume themes and auto-play slider
- Botanical product presentation with layered depth
- Infinite announcement ticker and curved section transition
- Editorial discovery mosaic
- Drag-to-scroll fragrance mood carousel
- Customer story cards
- Promotional offer panels and newsletter sign-up
- GSAP reveal/parallax motion and Lenis smooth scrolling
- Reduced-motion support
- Responsive desktop, tablet and mobile layouts

## Run locally

```bash
php -S localhost:8000
```

Open `http://localhost:8000`.

## Stack

- PHP 8+
- Bootstrap 5.3
- Bootstrap Icons
- GSAP + ScrollTrigger
- Lenis smooth scroll
- Vanilla JavaScript
